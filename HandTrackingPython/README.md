# Hand Tracking (ฝั่ง Python)

โฟลเดอร์นี้คือ**สำเนา**ของโค้ดฝั่ง Python ที่ใช้ตรวจจับมือ (hand tracking) แล้วส่งข้อมูลไปให้ฝั่ง Unity
เก็บไว้ในนี้ (อยู่ใน git repo เดียวกับ Unity project) เพื่อให้ใครก็ตามที่ clone repo นี้ไปได้โค้ดฝั่ง Python
ติดไปด้วยเลย ไม่ต้องไปขอไฟล์แยกกันอีกที

> ⚠️ ที่ทำงานจริงประจำวันของทีมอยู่คนละที่ (นอก repo นี้) โฟลเดอร์นี้เป็นสำเนาที่จะอัปเดตให้ตรงกัน
> ทุกครั้งที่โค้ดฝั่ง Python มีการแก้ไข ถ้าเห็นว่าไฟล์ในนี้เก่ากว่าที่ทีมใช้งานจริง ให้ทักไว้เพื่ออัปเดต

## ติดตั้ง

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate

pip install -r requirements.txt
```

ต้องมีกล้องเว็บแคมต่ออยู่ และไฟล์โมเดล `hand_landmarker.task` (แนบมาในโฟลเดอร์นี้แล้ว) ใช้โดย MediaPipe/cvzone
สำหรับตรวจจับ landmark ของมือ

## ไฟล์ในโฟลเดอร์นี้

- **`hand_detector_z.py`** — ตัวตรวจจับมือ (patch จาก `cvzone.HandTrackingModule.HandDetector` ให้ดึงค่า z
  จริงจาก MediaPipe แทนที่จะ hardcode เป็น 0)
- **`gesture_classifier.py`** — จำแนกท่ามือจากจุด landmark เป็น `"fist"` (กำมือ) / `"open"` (แบมือ) /
  `"other"` (อื่นๆ) โดยเช็คจากนิ้วชี้ กลาง นาง ก้อย (ไม่รวมโป้ง) พร้อม `GestureStabilizer` กันสถานะกระพริบ
  จากความไม่นิ่งของการตรวจจับ (ต้องเจอค่าเดิมซ้ำกันติดต่อกันครบตามที่กำหนดก่อนถึงจะเปลี่ยนสถานะจริง)
- **`udp_sender.py`** — ส่งข้อมูลจุด landmark ของมือ (21 จุด) + สถานะท่ามือ เป็น JSON ผ่าน UDP ไปยัง Unity
- **`video_streamer.py`** — เปิด TCP server ไว้สตรีมภาพสดจากกล้องไปให้ Unity แสดงผล (ใช้เมื่อซีนต้องโชว์
  ภาพกล้องด้วย เช่นซีน jigsaw puzzle หรือจอพรีวิวเล็กๆ ในซีน Flappy Bird เพราะกล้องตัวเดียวกันเปิดพร้อมกัน
  สองโปรเซสไม่ได้)
- **`Main.py`** — สคริปต์หลัก **ตัวเดียวใช้ได้กับทุกซีน** ไม่ต้องสลับสคริปต์ตามซีนที่เล่นใน Unity อีกต่อไป
  (แม้ Unity จะถูก build เป็นโปรแกรมจริงแล้วสลับซีนไปมา ก็ยังใช้ตัวนี้ตัวเดียวได้เหมือนเดิม) ทำหน้าที่:
  ส่ง landmark + สถานะท่ามือ ผ่าน UDP พอร์ต **5052** และสตรีมภาพผ่าน TCP พอร์ต **5053** พร้อมกันตลอดเวลา
- **`main_jigsaw.py`** — *เลิกใช้แล้ว* (ฟีเจอร์ถูกรวมเข้า `Main.py` หมดแล้ว) เหลือไว้แค่ข้อความเตือนเผื่อใครเปิดผิด
- **`hand_landmarker.task`** — ไฟล์โมเดลของ MediaPipe ที่ `HandDetectorZ` ต้องใช้
- **`requirements.txt`** — รายชื่อ Python package ที่ต้องติดตั้ง

## วิธีรัน

```bash
python Main.py
```

รันทิ้งไว้ตัวเดียว แล้วสลับเล่นซีนไหนใน Unity ก็ได้ (SampleScene / Flappy Bird / jigsaw) ฝั่ง Unity แต่ละซีน
จะดึงข้อมูลที่ต้องใช้เองจากตัวรับกลาง ไม่ต้องเปิด/ปิด/สลับสคริปต์ Python ตามซีนอีกต่อไป

## รูปแบบข้อมูลที่ส่งไป Unity (UDP พอร์ต 5052)

```json
{"hand_detected": true, "landmarks": [x0, y0, z0, x1, y1, z1, ...], "gesture": "fist"}
```

`gesture` เป็นได้ 4 ค่า: `"fist"` (กำมือ), `"open"` (แบมือ), `"other"` (ท่าอื่นๆ), `"none"` (ไม่พบมือ)

## พอร์ตที่ใช้

| พอร์ต | โปรโตคอล | ใช้ทำอะไร |
|---|---|---|
| 5052 | UDP | ส่งจุด landmark ของมือ (21 จุด) + สถานะท่ามือ |
| 5053 | TCP | สตรีมภาพสดจากกล้อง |

## ฝั่ง Unity ที่เกี่ยวข้อง

- **`HandTrackingHub.cs`** — ตัวรับ UDP กลางของทั้งเกม เปิด socket แค่ตัวเดียวตลอดอายุเกม (อยู่ข้ามซีน)
  ทุกสคริปต์ใน Unity ดึงข้อมูลมือ/ท่ามือล่าสุดจากตัวนี้ตัวเดียว ไม่มีใครเปิด socket เองอีก
- **`HandTrackingReceiver.cs`** — ใช้ใน SampleScene แสดงจุด landmark เป็นลูกบอล 21 ลูก (เครื่องมือทดสอบ)
- **`WebcamStreamReceiver.cs`** — รับภาพสดจาก `video_streamer.py` ผ่าน TCP
- **`FlappyHandHUD.cs`** — จอพรีวิวเล็กๆ มุมขวาบนในซีน Flappy Bird โชว์ภาพสด + สถานะท่ามือปัจจุบัน
- **`Birb_control.cs`** (`PlayerController`) — กำมือ (fist) ค้างไว้ = นกลอยขึ้นค้าง เหมือนกดปุ่ม Space ค้าง
  (ปุ่ม Space ยังใช้งานได้ตามปกติ เป็นแค่ทางเลือกเสริม)
